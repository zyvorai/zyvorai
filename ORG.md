# zyvorai GitHub organization map

Org / account: [github.com/zyvorai](https://github.com/zyvorai)

Most repos carry a historical `zyvor-` prefix (`zyvor-kryton`, `zyvor-haven`, `zyvor-fluxvm`); a few use `zyvorai-` (`zyvorai-fabric`, `zyvorai-argus`, `zyvorai-fleet`); the rest are unprefixed (`scout`, `iris`, `veyron`). Marketing names on [zyvor.dev](https://zyvor.dev) drop the prefix.

Public brand is **Zyvor** (not “Zyvor AI Labs”). Legal entity **ZyvorAI Labs Private Limited** stays in copyright/LICENSE only.

Only **public** repos are listed with links. Private products (Axiom, Ragnarok, Forge, PacketWolf, IronWolf, Relay, Zynera, Elvora, the website and enterprise editions) are documented on [zyvor.dev](https://zyvor.dev) only.
