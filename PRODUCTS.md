# Zyvor product catalog (selling guide)

Canonical pages live on **[zyvor.dev/products](https://zyvor.dev/products)** and **[zyvor.dev/compare](https://zyvor.dev/compare)**. Use this file for GitHub / partner one-pagers.

## Migrate

### HyperSDK Platform
- **Pitch:** Multi-cloud VM migration control plane — discover, export, convert, deploy.
- **Buy when:** Leaving a proprietary hypervisor / HCI, multi-site export, regulated air-gap bundles.
- **CTA:** [Product](https://zyvor.dev/hypersdk) · [Trial](https://zyvor.dev/contact?intent=trial&product=hypersdk) · [Demo](https://zyvor.dev/schedule)

### hyper2kvm
- **Pitch:** Disk conversion engine — VMDK/VHD/QCOW → boot-ready KVM artifacts.
- **Buy when:** Throughput and guest repair in the conversion path matter more than a wizard alone.
- **CTA:** [Product](https://zyvor.dev/hyper2kvm) · [GitHub](https://github.com/zyvorai/hyper2kvm)

### GuestKit
- **Pitch:** Offline disk intelligence — inspect, repair, SBOM, cutover passport without guest boot.
- **Buy when:** Pre-migration assurance and IR / forensic disk workflows.
- **CTA:** [Product](https://zyvor.dev/guestkit) · [GitHub](https://github.com/zyvorai/guestkit)
